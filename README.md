# F1 Telemetry Data Extractor

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![Issues](https://img.shields.io/github/issues/YourUsername/YourRepoName)](https://github.com/YourUsername/YourRepoName/issues)
[![Pull Requests](https://img.shields.io/github/issues-pr/YourUsername/YourRepoName)](https://github.com/YourUsername/YourRepoName/pulls)

This repository contains scripts to extract and process Formula 1 telemetry data using the `fastf1` library. The scripts are optimized for performance and can handle large amounts of data, saving it in a structured hierarchy of JSON files.

## Data Analysis

The JSON data generated by these scripts is structured for easy analysis and visualization. You can use various tools and platforms to explore the data, such as:

- **[TracingInsights](https://tracinginsights.com)**
- **[F1Tel](https://f1tel.com)**

These platforms provide tools to visualize telemetry, compare laps, and gain insights into driver performance.

## Dependencies

The project relies on the following Python libraries:

- `fastf1`
- `orjson`
- `psutil`
- `urllib3`
- `pyarrow`
- `joblib`

You can install them using pip:
```bash
pip install -r requirements.txt
```

## Directory Structure

The data is organized by event and session. For each event (e.g., "Australian Grand Prix"), a directory is created. Inside this directory, there are subdirectories for each session (e.g., "Practice 1", "Qualifying", "Race").

```
<Event Name>/
└── <Session Name>/
    ├── drivers.json
    ├── corners.json
    └── <Driver Abbreviation>/
        ├── laptimes.json
        └── {lap_number}_tel.json
```

## JSON File Documentation

### `drivers.json`

This file lists all drivers who participated in the session.

**Location:** `<Event Name>/<Session Name>/drivers.json`

**Structure:**
The file contains a JSON object with a single key `drivers`, which holds a list of driver objects.

| Key      | Type   | Description                                 |
|----------|--------|---------------------------------------------|
| `driver` | String | The driver's three-letter abbreviation (e.g., "VER"). |
| `team`   | String | The name of the driver's team.              |

**Example:**
```json
{
  "drivers": [
    {
      "driver": "VER",
      "team": "Red Bull Racing"
    },
    {
      "driver": "HAM",
      "team": "Mercedes"
    }
  ]
}
```

### `corners.json`

This file provides information about the circuit's corners, which is essential for plotting track maps and analyzing cornering performance.

**Location:** `<Event Name>/<Session Name>/corners.json`

**Structure:**
The file contains a single JSON object with keys mapping to lists of values. Each index in the lists corresponds to a specific corner on the circuit.

| Key            | Type           | Description                                                              |
|----------------|----------------|--------------------------------------------------------------------------|
| `CornerNumber` | List of Int    | The number of each corner.                                               |
| `X`            | List of Float  | The X-coordinate of each corner on the circuit map.                      |
| `Y`            | List of Float  | The Y-coordinate of each corner on the circuit map.                      |
| `Angle`        | List of Float  | The angle of each corner in degrees.                                     |
| `Distance`     | List of Float  | The distance in meters along the track to each corner.                   |
| `Rotation`     | Float          | The rotation of the circuit map in degrees for correct orientation.      |

**Example:**
```json
{
  "CornerNumber": [1, 2, 3],
  "X": [123.45, 234.56, 345.67],
  "Y": [456.78, 567.89, 678.90],
  "Angle": [90.0, -45.0, 180.0],
  "Distance": [350.5, 750.2, 1100.8],
  "Rotation": -15.5
}
```

### `laptimes.json`

This file contains a summary of all laps completed by a specific driver during the session.

**Location:** `<Event Name>/<Session Name>/<Driver Abbreviation>/laptimes.json`

**Structure:**
The JSON object contains several keys, each mapping to a list of values. Each index in the lists corresponds to a specific lap number.

| Key        | Type              | Description                                                                 |
|------------|-------------------|-----------------------------------------------------------------------------|
| `time`     | List of Float/Str | Lap time in seconds. "None" for incomplete laps.                            |
| `lap`      | List of Int       | The lap number.                                                             |
| `compound` | List of String    | The tire compound used (e.g., "SOFT", "MEDIUM"). "None" if unknown.          |
| `stint`    | List of Int/Str   | The stint number for the set of tires. "None" if unknown.                   |
| `s1`, `s2`, `s3` | List of Float/Str | Sector times in seconds. "None" if not available.                         |
| `life`     | List of Int/Str   | Number of laps the tires had been used for. "None" if unknown.              |
| `pos`      | List of Int/Str   | The driver's position at the end of the lap. "None" if unknown.             |
| `status`   | List of String    | The track status during the lap (e.g., "1" for green flag). "None" if unknown.|
| `pb`       | List of Bool/Str  | `True` if the lap was a personal best. "None" if not applicable.            |

**Example:**
```json
{
  "time": [95.123, 94.567],
  "lap": [1, 2],
  "compound": ["SOFT", "SOFT"],
  "stint": [1, 1],
  "s1": [28.1, 27.9],
  "s2": [35.2, 35.0],
  "s3": [31.823, 31.667],
  "life": [1, 2],
  "pos": [5, 5],
  "status": ["1", "1"],
  "pb": [false, true]
}
```

### `{lap_number}_tel.json`

These files contain detailed, high-resolution telemetry data for a single lap.

**Location:** `<Event Name>/<Session Name>/<Driver Abbreviation>/{lap_number}_tel.json`

**Structure:**
The file contains a main JSON object with a single key `tel`. The `tel` object holds the telemetry data streams as lists of values, where each index represents a single timestamped reading during the lap.

| Key            | Type           | Description                                                                 |
|----------------|----------------|-----------------------------------------------------------------------------|
| `time`         | List of Float  | Elapsed time in seconds from the start of the lap.                          |
| `rpm`          | List of Int    | Engine revolutions per minute.                                              |
| `speed`        | List of Int    | Car speed in km/h.                                                          |
| `gear`         | List of Int    | Current gear (0 for neutral, 1-8 for forward).                              |
| `throttle`     | List of Int    | Throttle application percentage (0-100).                                    |
| `brake`        | List of Int    | Brake application (1 for on, 0 for off).                                    |
| `drs`          | List of Int    | Drag Reduction System status (1 for active, 0 for inactive).                |
| `distance`     | List of Float  | Distance covered in meters from the start of the lap.                       |
| `rel_distance` | List of Float  | Relative distance covered in the lap, normalized from 0.0 to 1.0.           |
| `acc_x`        | List of Float  | Longitudinal acceleration (g-force).                                        |
| `acc_y`        | List of Float  | Lateral acceleration (g-force).                                           |
| `acc_z`        | List of Float  | Vertical acceleration (g-force).                                            |
| `x`, `y`, `z`  | List of Int    | The car's position in 3D space on the circuit map.                          |
| `dataKey`      | String         | A unique identifier for the lap data.                                       |

**Example:**
```json
{
  "tel": {
    "time": [0.1, 0.2, ...],
    "rpm": [11000, 11050, ...],
    "speed": [301, 302, ...],
    "gear": [8, 8, ...],
    "throttle": [100, 100, ...],
    "brake": [0, 0, ...],
    "drs": [1, 1, ...],
    "distance": [5.1, 10.2, ...],
    "rel_distance": [0.001, 0.002, ...],
    "acc_x": [0.5, 0.4, ...],
    "acc_y": [0.1, 0.1, ...],
    "acc_z": [1.0, 1.0, ...],
    "x": [10, 12, ...],
    "y": [20, 22, ...],
    "z": [5, 5, ...],
    "dataKey": "2025-Australian Grand Prix-Race-VER-25"
  }
}
```
